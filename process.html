Phase 03 · Privacy and isolation

The hardest engineering problem wasn't the AI. It was making sure one user's data could never leak into another's experience. Every read path — chat retrieval, the posts page, the digest, the suggested questions, even the post count shown in the UI — joins through a per-user visibility table. This is enforced at the database level, not the UI level.
